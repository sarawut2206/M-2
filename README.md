# IS Smart Writer — เวอร์ชัน 2

เว็บแอปสำหรับนักเรียน ม.2 เพื่อบันทึกข้อมูลการสร้างนวัตกรรม แนบภาพ ให้ AI เรียบเรียงบทที่ 3 และส่งออกเป็น Word (.docx) พร้อมระบบแยก 15 กลุ่มและแดชบอร์ดครู

## สถาปัตยกรรม
```
นักเรียน/ครู (มือถือหรือคอมพิวเตอร์)
        │  เปิดเว็บ static
        ▼
GitHub Pages  https://<user>.github.io/M-2/        ← โฟลเดอร์ app/ (Next.js export)
        │  POST (JSON) พร้อมโทเคนล็อกอิน
        ▼
Google Apps Script Web App                         ← apps-script/Code.gs
        ├── Google Sheet: Groups / Projects / Photos  (ฐานข้อมูล)
        ├── Google Drive: ไฟล์รูป (ส่วนตัว)
        └── OpenAI API (คีย์เก็บใน Script Properties)
```
ไฟล์ Word สร้างในเบราว์เซอร์ของผู้ใช้ (ไลบรารี docx) ไม่ผ่านเซิร์ฟเวอร์

## สิ่งที่ทำได้
- **นักเรียน**: เข้าด้วย *หมายเลขกลุ่ม + PIN 6 หลัก* → กรอกฟอร์ม แนบรูป (ย่อเป็น JPEG อัตโนมัติ) → สร้างร่างบทที่ 3 → แก้ข้อความในร่างเอง → ดาวน์โหลด Word → “ส่งงานให้ครู”
- **ข้อมูลอยู่ใน Google Sheet** สมาชิกในกลุ่มเปิดจากมือถือคนละเครื่องก็เห็นข้อมูลเดียวกัน บันทึกอัตโนมัติ ถ้าสองเครื่องแก้พร้อมกันระบบเตือนให้เลือก ไม่เขียนทับเงียบ ๆ
- **แยกกลุ่ม**: ตรวจสิทธิ์ที่ Apps Script ทุกคำขอ กลุ่มหนึ่งเห็นเฉพาะงานและรูปของตัวเอง
- **ครู** (`/teacher/`): ดูความคืบหน้า 15 กลุ่ม ดูร่างบทที่ 3 ดาวน์โหลด Word ของกลุ่มใดก็ได้ เขียนข้อความถึงกลุ่ม สร้าง/รีเซ็ต PIN (พิมพ์ใบแจกได้)
- **AI**: เรียกที่ Apps Script (คีย์ไม่ถึงเบราว์เซอร์ ต้องล็อกอินก่อน) ไม่ส่งรูปไป AI ถ้าไม่ตั้งคีย์จะใช้โหมดร่างเบื้องต้น
- **Word**: TH Sarabun New 16 pt (ตั้งทั้งชุดละตินและชุดอักษรไทย), A4, ตารางวัสดุ, รูปคงสัดส่วนพร้อมคำบรรยาย “ภาพที่ 3.x”

## ติดตั้งออนไลน์
1. **หลังบ้าน**: ทำตาม [apps-script/README.md](apps-script/README.md) จนได้ URL ของเว็บแอป (ลงท้าย `/exec`)
2. **ใส่ URL**: แก้ `.env.production` → `NEXT_PUBLIC_API_URL=<URL>`
3. **GitHub**: อัปโหลดโปรเจกต์นี้ขึ้น repository `M-2` (branch `main`) แล้วไปที่ Settings → Pages → Source เลือก **GitHub Actions** ไฟล์ [.github/workflows/deploy.yml](.github/workflows/deploy.yml) จะ build และเผยแพร่ให้ทุกครั้งที่ push
4. เปิด `https://sarawut2206.github.io/M-2/` (นักเรียน) และ `/teacher/` (ครู)

ถ้าเปลี่ยนชื่อ repository ให้ตั้ง `NEXT_PUBLIC_BASE_PATH` (เช่น `/ชื่อใหม่`) ใน workflow หรือแก้ค่าใน [next.config.ts](next.config.ts)

## รันในเครื่อง
ต้องมี Node.js 20+

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` ต้องตั้ง `NEXT_PUBLIC_API_URL` ก่อน (คัดลอก `.env.example` เป็น `.env.local`) หรือลองกับตัวจำลองโดยไม่ต้องติดตั้ง Apps Script:

```bash
node apps-script/mock-server.js
```
แล้วตั้ง `NEXT_PUBLIC_API_URL=http://localhost:8787` (ตัวจำลองพิมพ์รหัสผ่านครูและ PIN ให้ดูตอนเริ่ม ข้อมูลหายเมื่อปิด)

## ไฟล์แม่แบบ Word ของโรงเรียน (ยังรอไฟล์ตัวอย่าง)
รูปแบบตอนนี้เป็นค่าชั่วคราวตามธรรมเนียมรายงานไทย เมื่อได้ไฟล์ตัวอย่าง ให้แก้ค่าที่ [lib/docTemplate.ts](lib/docTemplate.ts) (ฟอนต์ ขนาดหัวข้อ ระยะขอบ ย่อหน้า ขนาดรูป) และโครงเอกสารที่ [lib/buildDocx.ts](lib/buildDocx.ts) ผู้ใช้ต้องมีฟอนต์ TH Sarabun New ในเครื่องที่เปิดไฟล์ Word

## ข้อจำกัดที่ควรรู้
- ความเร็วของ Apps Script (1–3 วินาทีต่อคำขอ) และข้อจำกัดอื่น ดูท้ายไฟล์ [apps-script/README.md](apps-script/README.md)
- โทเคนล็อกอินเก็บใน localStorage ของเบราว์เซอร์ (อายุ 14 วัน) ถ้าใช้เครื่องสาธารณะควรกด “ออกจากระบบ” ทุกครั้ง
- PIN เก็บเป็นค่าแฮชเท่านั้น ลืมแล้วดูย้อนหลังไม่ได้ ต้องให้ครูรีเซ็ต
- ใครเปิดไฟล์ Word ต้องมีฟอนต์ TH Sarabun New ไม่เช่นนั้น Word จะแทนด้วยฟอนต์อื่น (ถ้าส่งต่อให้ครูที่ไม่มีฟอนต์ ให้บันทึกเป็น PDF)
