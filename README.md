# IS Smart Writer — ต้นแบบเวอร์ชัน 1

เว็บแอปสำหรับนักเรียน ม.2 เพื่อบันทึกข้อมูลการสร้างนวัตกรรม แนบภาพ เรียบเรียงบทที่ 3 และส่งออกเป็น Word (.docx)

## สิ่งที่ทำได้ในต้นแบบนี้
- ฟอร์มข้อมูลโครงงาน วัสดุ ขั้นตอน และการทดลอง
- เพิ่ม/ลบวัสดุและขั้นตอน
- แนบรูปภาพจากโทรศัพท์หรือคอมพิวเตอร์
- บันทึกอัตโนมัติในเบราว์เซอร์เครื่องที่ใช้งาน
- สร้างร่างรายงานด้วย AI เมื่อกำหนด OpenAI API key
- มีโหมดร่างเบื้องต้นเมื่อยังไม่กำหนด API key
- ส่งออกไฟล์ Word จริง (.docx) และฝังรูปภาพที่แนบไว้ในเอกสาร

## ข้อจำกัดของเวอร์ชัน 1
ข้อมูลจะถูกบันทึกในเบราว์เซอร์ของอุปกรณ์นั้นเท่านั้น ยังไม่ซิงก์ข้ามมือถือ/คอมพิวเตอร์ และยังไม่มีระบบล็อกอินกลุ่ม/แดชบอร์ดครูแบบออนไลน์ ก่อนเปิดให้นักเรียน 10–15 กลุ่มใช้งานจริง ควรเพิ่มฐานข้อมูลและระบบยืนยันตัวตน (เช่น Supabase) รวมถึงกำหนดสิทธิ์แยกแต่ละกลุ่ม

## ต้องเตรียมก่อนใช้งาน
- Node.js 20 หรือใหม่กว่า
- OpenAI API key (ถ้าต้องการให้ AI เรียบเรียงจริง)
- ไฟล์ Word แม่แบบของโรงเรียน (ยังไม่ได้รับในขั้นตอนนี้ จึงใช้รูปแบบมาตรฐานชั่วคราว)

## วิธีเปิดใช้งานในเครื่อง
1. แตกไฟล์ ZIP
2. เปิด Terminal ในโฟลเดอร์ `is-smart-writer`
3. ติดตั้ง dependencies:

   ```bash
   npm install
   ```

4. คัดลอก `.env.example` เป็น `.env.local` และใส่ API key:

   ```env
   OPENAI_API_KEY=ใส่คีย์ของคุณ
   OPENAI_MODEL=gpt-6-astra
   ```

   ใช้ชื่อโมเดลที่เปิดให้ใช้ในบัญชี API ของคุณ หากยังไม่มี API key สามารถใช้โหมดร่างเบื้องต้นได้

5. เปิดเว็บไซต์:

   ```bash
   npm run dev
   ```

6. เข้า `http://localhost:3000`

## ก่อนนำขึ้นออนไลน์
ต้องเพิ่มฐานข้อมูลและระบบล็อกอินกลุ่มก่อน เพราะ localStorage ไม่เหมาะกับการส่งงานจากอุปกรณ์หลายเครื่อง แนะนำให้ใช้ Supabase Auth/Database/Storage พร้อม Row Level Security และเก็บ API key ไว้ฝั่งเซิร์ฟเวอร์เท่านั้น

## ไฟล์แม่แบบ Word ของโรงเรียน
เมื่อได้รับไฟล์ Word ตัวอย่างแล้ว ให้ปรับ:
- ขนาดกระดาษและระยะขอบ
- รูปแบบหัวข้อและเลขลำดับ
- ฟอนต์ TH Sarabun New และขนาดตัวอักษร
- ระยะบรรทัดและการจัดตำแหน่งรูป
- รูปแบบตารางและคำบรรยายภาพ
