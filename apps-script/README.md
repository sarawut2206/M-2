# ติดตั้งระบบหลังบ้าน (Google Apps Script + Google Sheets)

ระบบหลังบ้านเก็บข้อมูลลง Google Sheet, เก็บรูปใน Google Drive, ตรวจ PIN/รหัสครู และเรียก AI ให้ ทั้งหมดอยู่ในไฟล์เดียว [Code.gs](Code.gs) หน้าเว็บบน GitHub Pages เรียกผ่าน URL ของ Web App

## ขั้นตอน (ทำครั้งเดียว ประมาณ 10 นาที)

1. **เปิดโปรเจกต์ Apps Script** — ใช้โปรเจกต์ที่เปิดอยู่แล้วได้เลย (แบบอิสระ ระบบจะสร้าง Google Sheet ใหม่ให้เอง) หรือจะเปิดจากชีตที่สร้างไว้ก็ได้: ชีต → ส่วนขยาย → Apps Script
2. **วางโค้ด** — เปิดไฟล์ `รหัส.gs` ลบของเดิมทั้งหมด วางเนื้อหาจาก [Code.gs](Code.gs) แล้วกดบันทึก (Ctrl+S)
3. **ตั้งเขตเวลา** (ไม่บังคับ) — การตั้งค่าโครงการ (รูปเฟือง) → เขตเวลา → `(GMT+07:00) กรุงเทพ`
4. **ตั้งรหัสลับ** — การตั้งค่าโครงการ → ด้านล่างสุด “พร็อพเพอร์ตีสคริปต์” → เพิ่มพร็อพเพอร์ตีสคริปต์

   | ชื่อ | ค่า | จำเป็น |
   |---|---|---|
   | `TEACHER_PASSWORD` | รหัสผ่านเข้าแดชบอร์ดครู (อย่างน้อย 8 ตัวอักษร) | ใช่ |
   | `OPENAI_API_KEY` | คีย์ OpenAI สำหรับให้ AI เรียบเรียง | ไม่ (ไม่ใส่ = โหมดร่างเบื้องต้น) |
   | `OPENAI_MODEL` | ชื่อโมเดลที่บัญชีของคุณใช้ได้ (ไม่ใส่ = `gpt-4o-mini`) | ไม่ |

5. **เรียกใช้ `setup`** — กลับไปที่เอดิเตอร์ เลือกฟังก์ชัน `setup` ในแถบด้านบน กด “เรียกใช้” → อนุญาตสิทธิ์ (หน้า “Google ยังไม่ได้ยืนยันแอปนี้” ให้กด *ขั้นสูง* → *ไปที่ … (ไม่ปลอดภัย)* เพราะเป็นสคริปต์ของคุณเอง) เมื่อเสร็จดูที่ “บันทึกการดำเนินการ” จะมีลิงก์ Google Sheet ที่สร้างให้ ถ้าขึ้นเตือน TEACHER_PASSWORD แปลว่ายังไม่ได้ทำข้อ 4
6. **เผยแพร่เป็นเว็บแอป** — ปุ่ม “การทำให้ใช้งานได้” → “การทำให้ใช้งานได้ใหม่” → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   
   กด “ทำให้ใช้งานได้” แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
7. **ใส่ URL ในเว็บ** — แก้ไฟล์ `.env.production` ในรากโปรเจกต์:

   ```
   NEXT_PUBLIC_API_URL=https://script.google.com/macros/s/xxxxxxxx/exec
   ```

   URL นี้ไม่ใช่ความลับ (ใครไม่มี PIN/รหัสครูก็ทำอะไรไม่ได้) จึงอัปโหลดขึ้น GitHub ได้
8. เปิด `https://<ชื่อผู้ใช้>.github.io/M-2/teacher/` → เข้าด้วยรหัสผ่านครู → กด “สร้าง PIN ให้กลุ่มที่ยังไม่มี” → พิมพ์แจกนักเรียน

## เมื่อแก้โค้ด Code.gs ภายหลัง
วางโค้ดใหม่ → บันทึก → การทำให้ใช้งานได้ → **จัดการการทำให้ใช้งานได้** → ไอคอนดินสอ → เวอร์ชัน = **เวอร์ชันใหม่** → ทำให้ใช้งานได้ (URL เดิมยังใช้ได้ ไม่ต้องแก้เว็บ) ถ้าสร้าง “การทำให้ใช้งานได้ใหม่” ทุกครั้ง URL จะเปลี่ยน

## โครงสร้างข้อมูลใน Google Sheet
| แผ่น | เก็บอะไร |
|---|---|
| `Groups` | แถวละกลุ่ม: ค่าแฮชของ PIN (ไม่ใช่ PIN จริง) |
| `Projects` | แถวละกลุ่ม: ข้อมูลโครงงานเป็น JSON, เวอร์ชัน, สถานะส่งงาน, ข้อความจากครู, เวลา |
| `Photos` | ดัชนีรูป: รหัสรูป, กลุ่มเจ้าของ, ไฟล์ใน Drive (โฟลเดอร์ `IS Smart Writer - photos`) |

**อย่าแชร์ Google Sheet และโฟลเดอร์รูปให้นักเรียน** นักเรียนเข้าถึงข้อมูลผ่านเว็บเท่านั้น ซึ่งตรวจสิทธิ์รายกลุ่มให้ ห้ามแก้แผ่น `Groups` และ `Projects` ด้วยมือ (ยกเว้นดูข้อมูลหรือแก้ข้อความ) เพราะอาจทำให้เวอร์ชันไม่ตรง

## ข้อจำกัดที่ควรรู้
- **บัญชี Google โรงเรียน (Workspace)**: ผู้ดูแลระบบบางโรงเรียนปิดการเผยแพร่เว็บแอปแบบ “ทุกคน” หรือจำกัดเฉพาะคนในโดเมน ถ้าตัวเลือก “ทุกคน” ไม่ขึ้น นักเรียนที่ไม่มีบัญชีโรงเรียนจะใช้ไม่ได้ ให้ลองใช้บัญชี Gmail ส่วนตัวเป็นเจ้าของสคริปต์แทน
- **ความเร็ว**: Apps Script ตอบช้ากว่าเซิร์ฟเวอร์ทั่วไป ครั้งละ 1–3 วินาที (ครั้งแรกหลังว่างนานอาจ 5 วินาที) เว็บจึงบันทึกอัตโนมัติหลังหยุดพิมพ์ 1 วินาทีและแสดงสถานะการบันทึกให้เห็น
- **ขนาดข้อมูล**: ข้อความโครงงานของแต่ละกลุ่มต้องไม่เกิน ~45,000 ตัวอักษร (ขีดจำกัดเซลล์ของ Google Sheets) และอัปโหลดรูปได้กลุ่มละ 60 รูป (ปรับที่ `MAX_PHOTOS_PER_GROUP`)
- **โควตา**: บัญชีทั่วไปรันพร้อมกันได้ ~30 คำสั่ง และเรียก OpenAI ได้วันละ ~20,000 ครั้ง เพียงพอสำหรับ 15 กลุ่ม
- **ป้องกันการเดา PIN**: ใส่ผิด 6 ครั้งต่อกลุ่ม ล็อก 10 นาที (ครูกดรีเซ็ต PIN เพื่อปลดล็อกทันที) การรีเซ็ต PIN หรือเปลี่ยน `TEACHER_PASSWORD` จะทำให้เซสชันเก่าใช้ไม่ได้
- **แก้พร้อมกัน**: ถ้าสมาชิกกลุ่มเดียวกันแก้พร้อมกัน ระบบเตือนและให้เลือกว่าจะใช้ข้อมูลของใคร (ไม่เขียนทับเงียบ ๆ)

## ทดสอบโค้ดโดยไม่ต้องติดตั้ง
```bash
node apps-script/mock-test.js     # ทดสอบตรรกะของ Code.gs กับตัวจำลอง Apps Script
node apps-script/mock-server.js   # เปิดเซิร์ฟเวอร์จำลองที่ localhost:8787 ไว้ลองหน้าเว็บ
```
ตัวจำลองไม่ใช่ Apps Script จริง จึงยืนยันได้เฉพาะตรรกะของโค้ด ไม่ครอบคลุมความต่างของสภาพแวดล้อมจริง (สิทธิ์ โควตา ความเร็ว) ให้ทดสอบกับของจริงอีกครั้งหลังติดตั้ง
